## 2. Implementation Planning Protocol (`IMPLEMENTATION.md`)
When the user requests new features, bug fixes, or code changes:
1. **Draft First:** Create or update the active plan in [`IMPLEMENTATION.md`](file:///c:/Users/PRANAV%20ADVA/OneDrive/Desktop/Ai-casino/IMPLEMENTATION.md) with:
   - Feature summary & objectives
   - Proposed architecture & design
   - Affected files and components
   - Phased execution checklist
   - Verification steps
2. **Approval Gate:** Present the plan to the user and **wait for their explicit confirmation to proceed** before writing or altering any project code.
3. **Execute Upon Confirmation:** Once the user confirms ("proceed", "yes", "go ahead", etc.), implement the approved plan step-by-step.
4. **Log & Finalize:** Check off items in [`IMPLEMENTATION.md`](file:///c:/Users/PRANAV%20ADVA/OneDrive/Desktop/Ai-casino/IMPLEMENTATION.md) and document the completed work in [`WALKTHROUGH.md`](file:///c:/Users/PRANAV%20ADVA/OneDrive/Desktop/Ai-casino/WALKTHROUGH.md).
